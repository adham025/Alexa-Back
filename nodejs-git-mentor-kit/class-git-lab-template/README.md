# class-git-lab

مستودع تدريبي لمسار Node.js — سيشن Git & GitHub.

## الهدف

كل طالب يعمل:

1. **Clone** هذا الـ repo
2. **Branch** من issue مفتوح
3. **Pull Request** → **Review** → **Squash merge**

## قواعد سريعة

- Branch: `fix/issue-N-yourname` أو `docs/add-student-yourname`
- commit message واضحة
- PR صغيرة — تعديل سطر أو سطرين
- لا ترفع secrets
