# Contributing

## Setup

```bash
git clone https://github.com/YOUR_ORG/class-git-lab.git
cd class-git-lab
```

## Workflow

1. Pick an open **Issue**
2. `git checkout -b fix/issue-N-githubusername`
3. Edit, then:

```bash
git add .
git commit -m "fix: resolve issue N — short description"
git push -u origin fix/issue-N-githubusername
```

4. Open **Pull Request** to `main`
5. Ask a peer for one review comment
6. **Squash and merge** when approved

## Branch names

- `fix/...` — typo or small fix
- `docs/...` — documentation / STUDENTS.md
